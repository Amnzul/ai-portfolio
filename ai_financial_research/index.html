Using Claude Desktop Skills and Rules for Investment Research

Applying AI Workflows to Financial Document Analysis

Project Overview

As I continued exploring practical applications of large language models, I became interested in using Claude Desktop to assist with financial investment research. Rather than asking isolated questions, I wanted to create a more structured workflow that could consistently analyze financial information and provide organized responses.

To accomplish this, I explored Claude Desktop's Skills and Rules features. These capabilities allowed me to build a repeatable research environment that reduced the need to restate instructions for every conversation.

Building a Structured Workflow

1. Create a Project to keep all the financial research together.

2. Upload rules to the new project.

3. Goto Settings in Claude Desktop. Choose Capabilities from the left menu, and scroll down to Skills.

4. Add the skills in the zip file here. Note: I received these skills from a friend, I did not create them myself.

5. Ask Claude to research a stock investment.

I configured Claude Desktop to work with collections of financial documents by providing reference files alongside clear instructions for how the information should be interpreted. Rather than treating each chat independently, I established a consistent framework that encouraged thorough and organized analysis.

The combination of Skills and Rules transformed Claude Desktop from a general-purpose chatbot into a specialized research assistant tailored to my preferred workflow.

Using Reference Files

One of the most useful capabilities was the ability to provide supporting files that Claude could reference during analysis. By organizing research materials and making them available within the conversation, I was able to ask questions with additional context and receive more focused, consistent responses.

This approach made it easier to compare information, summarize key points, and review financial material without repeatedly uploading or describing the same documents.

Lessons Learned

This project reinforced an important lesson about working with AI: obtaining useful results depends not only on the model itself but also on designing an effective workflow. Well-defined instructions, supporting documentation, and consistent operating rules significantly improve the quality and reliability of AI-assisted research.

I also gained a greater appreciation for prompt engineering and workflow design. Using reusable instructions reduced repetitive tasks and made my research sessions more efficient and organized.

Reflection

Exploring Claude Desktop's Skills and Rules demonstrated how large language models can be customized for domain-specific tasks. While I used these features for financial investment research, the same principles could be applied to many other knowledge-intensive workflows.

This experience expanded my understanding of AI beyond simple prompting and introduced me to the value of building structured, reusable AI workflows that improve both productivity and consistency.
